# 🎮 Nexus - Plataforma Educacional para Desenvolvimento de Jogos (Protótipo UI/UX)

> **⚠️ AVISO:** Este repositório contém o **design conceitual e o protótipo navegável** da plataforma construído no **Figma**. O projeto atual é uma demonstração visual e interativa de Experiência do Usuário (UX/UI), e não uma aplicação funcional em código.

A **Nexus** é uma ideia de plataforma educacional desenhada para democratizar e estruturar o aprendizado de criação de jogos. Nosso objetivo com este protótipo é ilustrar como podemos eliminar a barreira de entrada e a frustração de desenvolvedores iniciantes, guiando-os na arquitetura de software.

## 🚀 O Conceito do Projeto

Muitos estudantes e desenvolvedores *indie* travam na complexidade de aprender a programar e desenhar um jogo ao mesmo tempo. Em vez de entregar tutoriais genéricos ou códigos prontos, a interface da Nexus foi desenhada para organizar o caos. O protótipo simula a divisão do desenvolvimento em etapas gerenciáveis (*Scaffolding*) usando uma inteligência artificial integrada como mentora.

O design do protótipo demonstra os nossos **3 Pilares Principais**:
1. **Planejamento Estruturado:** Telas simulando como a IA geraria checklists lógicos (ex: mapear inputs, estruturar POO, criar diagramas UML) antes do usuário escrever código.
2. **Tutoria em Tempo Real:** Interfaces mostrando como a **Nexus AI** analisaria a lógica do projeto para sugerir estruturas de dados e arquitetura direto no editor.
3. **Prática Ativa:** Fluxos de tela criados para mostrar que a plataforma não entrega o código pronto, mas sim ensina o raciocínio por trás do desenvolvimento em uma IDE integrada fictícia.
